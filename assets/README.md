# Fluent BCMath logo assets

The mark combines a flowing lowercase f with two parallel equality strokes, in blue and teal.

| File | Background |
| --- | --- |
| `logo-transparent.png` | Transparent RGBA |
| `logo-light.png` | White |
| `logo-dark.png` | Deep midnight navy |

All variants are 1254 x 1254 pixel square PNG images. The transparent master is intended for embedding on custom backgrounds.

Generated with the built-in imagegen tool. The background variants use the transparent master as their edit target.
